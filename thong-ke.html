Cách gắn bảng thống kê này vào epsilon-class-1.pages.dev

Chỉ cần làm 2 bước dưới đây là anh có ngay trang thống kê Tiếng Việt y hệt hình mẫu.

1 Lưu file này thành thong-ke.html trong thư mục web của anh

Đặt file thong-ke.html cùng chỗ với file index.html của dự án epsilon-class-1. Sau khi đẩy lên Cloudflare Pages, anh mở đường dẫn https://epsilon-class-1.pages.dev/thong-ke.html là xem được bảng này bất cứ lúc nào.

2 Dán đoạn mã đếm tự động này vào cuối file index.html (trước thẻ </body>) 
<!-- Bộ đếm lượt xem & số người truy cập cho epsilon-class-1.pages.dev -->
<script>
(function() {
  const NAMESPACE = 'epsilon-class-1-pages-dev';
  const today = new Date().toISOString().slice(0, 10);
  const path = window.location.pathname || '/';
  const ref = document.referrer || '';
  
  // 1. Phân biệt khách riêng biệt (Unique Visitor)
  let uid = localStorage.getItem('eps_uid');
  let isNewUserToday = false;
  if (!uid) {
    uid = 'u_' + Math.random().toString(36).slice(2) + Date.now().toString(36);
    localStorage.setItem('eps_uid', uid);
  }
  if (localStorage.getItem('eps_last_day') !== today) {
    isNewUserToday = true;
    localStorage.setItem('eps_last_day', today);
  }

  // 2. Gửi tín hiệu sang trang thong-ke.html và API đếm miễn phí
  try {
    const bc = new BroadcastChannel('epsilon_analytics_channel');
    bc.postMessage({ type: 'visit', path, ref, isNewUserToday, date: today });
  } catch(e) {}

  fetch('https://api.counterapi.dev/v1/' + NAMESPACE + '/views/up').catch(() => {});
  if (isNewUserToday) {
    fetch('https://api.counterapi.dev/v1/' + NAMESPACE + '/users/up').catch(() => {});
  }
})();
</script>

✓ Đã sao chép đoạn mã vào bộ nhớ tạm!

Đồng bộ số liệu toàn cầu (CounterAPI miễn phí)

Đoạn mã ở Bước 2 đã tích hợp sẵn CounterAPI (`epsilon-class-1-pages-dev`) hoàn toàn miễn phí. Mỗi khi học sinh hoặc bất kỳ ai mở trang web của anh trên điện thoại/máy tính khác, tổng số lượt xem và số người thực tế sẽ tự động cộng dồn lên đám mây và hiển thị trên bảng thống kê này!
